# ネットネット株スクリーナー(かぶ1000流)

JPX全上場銘柄(約4,000銘柄)を対象に、かぶ1000流のネットネット株(超割安株)を
抽出するスクリーナーです。

## 判定ロジック

```
正味流動資産   = 現金及び預金 + 受取手形及び売掛金 + 有価証券 + 投資有価証券 − 負債合計
ネットネット指数 = 時価総額 ÷ 正味流動資産
```

- **抽出条件**: 正味流動資産 > 0 かつ ネットネット指数 < 1.0
- **グレアム基準フラグ**: ネットネット指数 < 0.67

## スマホだけで実行する (GitHub Actions)

PCと同じコード・同じデータで実行されるため精度は同一です。スマホからは
実行ボタンを押して結果を見るだけで完結します。

1. スマホのブラウザで GitHub のこのリポジトリを開く
   (github.com にログイン → リポジトリ → **Actions** タブ)
2. 左のワークフロー一覧から **net-net-screener** を選ぶ
3. **Run workflow** ボタンを押し、ブランチ(このブランチ)を選んで実行
   - オプションは空欄のままでOK(全銘柄・キャッシュ利用)
   - 初回は2〜4時間程度かかります。途中で失敗・タイムアウトしても
     取得済みデータはキャッシュされるので、もう一度実行すれば続きから再開します
4. 完了するとリポジトリの `results/` フォルダに結果がコミットされます
   - **`results/summary.md`** — 上位30銘柄と傾向サマリー(スマホで開くと整形表示されて読みやすい)
   - `results/net_net_results.csv` — 抽出銘柄の全列
   - `results/all_data.csv` / `results/skipped.csv` — 検証用・スキップログ

毎週の自動実行にしたい場合は `.github/workflows/screener.yml` 内の
`schedule:` のコメントを外してデフォルトブランチにマージしてください
(GitHubの仕様でscheduleはデフォルトブランチでのみ動作します)。
プライベートリポジトリの場合、無料枠のActions実行時間(月2,000分)を
1回あたり120〜240分消費する点にご注意ください。

## セットアップ (PCで実行する場合)

```bash
pip install -r requirements.txt
```

## 使い方

```bash
# 全銘柄スクリーニング(初回は数時間かかります)
python net_net_screener.py

# 動作確認: 先頭100銘柄のみ
python net_net_screener.py --limit 100

# 特定銘柄のみ
python net_net_screener.py --codes 7203 8306

# キャッシュを無視して再取得
python net_net_screener.py --refresh
```

### 主なオプション

| オプション | 説明 |
|---|---|
| `--limit N` | 先頭N銘柄のみ処理(動作確認用) |
| `--codes C1 C2 ...` | 指定銘柄コードのみ処理 |
| `--refresh` | 財務データのキャッシュを無視して再取得 |
| `--refresh-list` | JPX銘柄リスト(data_j.xls)を再ダウンロード |
| `--strict` | 有価証券・投資有価証券が欠損の銘柄もスキップする |
| `--sleep S` | 銘柄間のスリープ秒(デフォルト0.6秒+ジッター) |

## 処理の流れ

1. **銘柄リスト取得** — JPX公式の上場銘柄一覧
   ([data_j.xls](https://www.jpx.co.jp/markets/statistics-equities/misc/01.html))
   をダウンロード。ETF・ETN・REIT・インフラファンド・カントリーファンド・
   ベンチャーファンド・出資証券を除外し、普通株のみを対象にします。
2. **データ取得** — yfinance(ティッカー `コード.T`)で時価総額・株価・PBR・
   貸借対照表(現金、売掛金、有価証券、投資有価証券、負債合計)・営業利益を取得。
   レート制限対策として銘柄間スリープ+失敗時は指数バックオフで3回リトライ。
   100銘柄ごとに進捗表示し、`cache/fundamentals.pkl` に逐次キャッシュ保存
   (再実行時はキャッシュ済み銘柄をスキップして途中から再開できます)。
3. **判定・出力** — ネットネット指数の昇順でソートし、CSV出力+上位30銘柄を
   コンソール表示。最後に業種の偏りと指数の分布のサマリーを表示します。

## 出力ファイル

| ファイル | 内容 |
|---|---|
| `net_net_results.csv` | 抽出銘柄(銘柄コード、銘柄名、株価、時価総額、正味流動資産、ネットネット指数、グレアム基準該当フラグ、PBR、直近営業利益、業種) |
| `all_data.csv` | 計算対象全銘柄の生データ+計算結果(検証用) |
| `skipped.csv` | スキップ銘柄とその理由 |

## データ上の注意

- **yfinance の財務データは連結/単体の別・項目名の揺れ・更新遅延により不正確な
  場合があります。抽出された上位銘柄は必ず最新の決算短信(貸借対照表)の原本で
  数値を確認してください。**
- Yahoo Finance は値がゼロの項目を行ごと省略するため、「有価証券」「投資有価証券」
  が取得できない場合は「保有なし(0)」として扱います(`--strict` で厳格にスキップ
  可能)。現金・売掛金・負債合計・時価総額のいずれかが欠損した銘柄はスキップし、
  理由を `skipped.csv` に記録します。
- 貸借対照表の項目名は銘柄により揺れるため、複数の候補キー
  (例: `Accounts Receivable` → `Receivables`)の first-hit で取得しています。
  採用したキーはキャッシュ内 `keys_used` に記録されます。
